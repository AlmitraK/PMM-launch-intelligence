# Founder / Executive LinkedIn POV

Coding is becoming agentic faster than production operations are.

An engineer can now ask an agent to write code, refactor a service, or ship a change. But when something goes wrong in production, the workflow often snaps back to the old model: open an observability UI, search manually, copy context, then explain it back to the agent.

That gap matters.

At the same time, AI workloads themselves are changing what observability systems have to process. LLM calls introduce model inference, tool calls, token streaming, databases, and surrounding application infrastructure into the same trace. In SigNoz data referenced for this launch, AI-native companies generate approximately **2.4× more telemetry**. **[VERIFY PUBLIC CLAIM WORDING BEFORE PUBLISHING.]**

We think observability for the AI era has to solve both problems:

**Agent-native:** production telemetry should be available where developers and their agents already work.

**AI-scale:** the observability system itself has to handle the larger traces and new signals AI workloads create.

That’s why the direction is bigger than MCP or an AI assistant by itself. MCP, Noz, our dashboard architecture, and our new trace experience are all pieces of the same shift.

The goal is simple: **a platform agents can run and engineers can trust.**
